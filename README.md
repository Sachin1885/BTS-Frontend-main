# Bus Tracking and Management System

This React frontend is a Bus Tracking and Management System designed for the PSIT campus. It helps students, drivers, and administrators manage transportation in one place.

## Features

1. **Live Tracking**: Real-time bus location updates using GPS data.
2. **Occupancy Monitoring**: Current occupancy information to help students plan their commute.
3. **Request System**: Students can raise requests when they miss their bus.
4. **Admin Panel**: Administrators can manage drivers, students, routes, and requests.

## Technology Stack

- **Frontend**: React, Vite, and React Router
- **HTTP Client**: Axios
- **Backend**: Go API

## Getting Started

Clone and install the project:

```sh
git clone https://github.com/Sachin1885/BTS-Frontend-main.git
cd BTS-Frontend-main
npm install
```

Create a local `.env` file with the backend URL:

```env
VITE_API_URL=http://127.0.0.1:8000/
```

Start the development server:

```sh
npm run dev
```

Create a production build:

```sh
npm run build
```

The `.env` file is ignored by Git. Do not commit API keys or other secrets.
